# Inventory Manager

## Overview

Inventory Manager is a simple console application written in Kotlin for managing a small product inventory.

The program allows users to add products, view the inventory, add or remove stock, and check which products are below their minimum stock level.

I created this project to improve my understanding of Kotlin and practice concepts such as variables, conditionals, loops, functions, classes, data classes, collections, and the `when` expression in a practical application.


## Development Environment

I developed this project using IntelliJ IDEA and the Kotlin programming language.

The application runs on the JVM using the Java Development Kit (JDK). Git and GitHub were used for version control and to publish the project.
